# Cómo ejecutar FinanzasMundo

## Requisitos

- Node.js >= 20
- npm >= 9

## Instalación

```bash
npm run install:all
```

## Ejecutar en modo desarrollo

```bash
npm run dev
```

Esto iniciará:
- **Backend API**: http://localhost:3001
- **Frontend**: http://localhost:5173

## Comandos útiles

```bash
# Solo backend
npm run dev:backend

# Solo frontend
npm run dev:frontend

# Build del frontend
npm run build

# Preview del build
npm run preview

# Linting
npm run lint

# Verificación completa
npm run check
```

## Listo

Abre http://localhost:5173 en tu navegador.
